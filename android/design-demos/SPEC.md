# 思佳围棋 App UI 重设计 · 三方向共用设计 Spec

## 产品是什么
「思佳围棋」是一款 Android 单机围棋 App（复刻 2007 年经典 PC 软件的移植版）。内核是 GNU Go 3.8 引擎（GTP 协议），纯本地运行，无网络、无账号、无内购。目标：把围棋的「静气」做出来——这是一个让人沉下心的产品，不是信息流产品。

## 目标受众与使用场景
- 围棋爱好者（入门到业余段位），利用碎片时间在手机上对弈或打谱
- 使用场景：单手竖屏握持，通勤、睡前、安静环境
- 观众距离：30cm 手机屏；视觉温度：安静、克制、可信赖

## 本次设计范围（两个屏幕，并排展示）
每版初稿 = 一张 1440×900 的展示页，**左右并排放两台手机框**（单台 390×844 逻辑像素，可等比缩放至 ≤860 高），左屏=主界面，右屏=对弈界面。页面底部用小字标注本方向的名称与一句话气质定位。

### 屏幕 1 · 主界面（必含真实内容）
- App 名：思佳围棋
- 副标：GNU Go 引擎 · 单机对弈
- 三个入口（真实文案）：
  1. 人机对弈 —— 与 GNU Go 引擎对局，可选等级与让子
  2. 本地双人 —— 两人同机对弈
  3. 棋谱欣赏 —— 吴清源 vs 本因坊秀哉 等名局
- 可选次要元素：版本号 v1.0.0、引擎署名「Powered by GNU Go」

### 屏幕 2 · 对弈界面（必含真实内容）
- 顶部状态条，二选一展示：「我执黑 ● 黑方行棋」或「形势：白领先约 9.4 目」
- 19×19 围棋棋盘（木色可再设计，不必拘泥原 #E3B771），含 9 个星位
- 棋型（真实对局快照，0-indexed 坐标，x=列左起 0..18，y=行上起 0..18）：
  - 黑子：(15,3) (3,3) (2,13) (15,15) (9,9) (13,4) (3,12)
  - 白子：(3,15) (15,12) (5,4) (12,12) (9,3) (4,9) (14,14)
  - 最后一手 = 白 (14,14)，需要有「最后一手」视觉标记
- 操作按钮六个：悔棋、停一手、形势、数子、认输、存谱
  （当前为两行：4 + 2；可重新组织，但六个都要在）

## 硬性约束
- 纯 HTML/CSS/JS 单文件，零外部图片；棋盘/棋子用 Canvas 或 CSS 绘制
- 字体：可用 Google Fonts CDN，但必须带本地中文字体 fallback（微软雅黑/宋体/楷体/黑体），截图环境可能无外网
- 可读性底线：手机框内正文 ≥14px、辅助文字 ≥12px，正文对比度 ≥4.5:1
- 禁止：紫色渐变、emoji 当图标、圆角卡片+左侧色条（Material 烂大街组合）、SVG 画人/画场景
- 棋子质感：黑白子要有基本立体感（径向渐变/阴影即可），不许纯平涂圆圈
- 三个方向的手机框样式可各自设计（圆角/边框/状态栏示意），但屏内内容必须一致，方便横向对比设计

## 当前 UI 的痛点（要解决的问题）
1. 主界面是三个白卡片+灰底，无任何围棋气质，像设置页
2. 对弈界面按钮是灰扑扑的 pill，层级扁平，「认输/存谱」与「悔棋/形势」无主次
3. 状态条纯文字居顶，无轮次氛围；棋盘与 UI 完全脱节（棋盘一块、按钮一块）
4. 无品牌记忆点：看不到「思佳围棋」是谁

## form 来自内容的哪里（母题提示，各方向自行诠释）
围棋独有的视觉母题候选：纵横 19 路的线格、黑白子的圆与虚实、木色棋盘、星位点、「气」与提子的呼吸感、棋谱记谱符号（●○/字母数字坐标）。每版设计必须让母题长在 UI 结构里，而不是贴一张背景图。
